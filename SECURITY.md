# Security policy

This policy applies to every repository in the nudgeist organization that
doesn't have its own `SECURITY.md`.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub: open the affected
repository and use **Security → Report a vulnerability**. For nudgeist
itself, that is
[nudgeist/nudgeist](https://github.com/nudgeist/nudgeist/security/advisories/new).
Don't open a public issue for security problems.

You'll get an acknowledgement as soon as the maintainer sees it, and a fix
or a decision will be coordinated with you before anything is disclosed.

## Supported versions

Only the latest release of each project receives fixes.
